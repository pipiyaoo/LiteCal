# 轻刻 LiteCal — 安卓本地科学减脂热量管理 App

一款零广告、纯本机数据库存储、专为中式饮食与外卖场景设计的安卓减脂热量追踪应用。

## 核心特性
- **双核仪表盘**：聚焦「今日剩余可吃大卡」与「蛋白质保肌达标」，弱化琐碎指标焦虑。
- **四合一极速录入**：
  1. **常吃单品 & 一键套餐模板**（点一下整餐入账）
  2. **双协议直连多模态 AI 估算**（支持拍照或一句话描述，兼容通义千问 Qwen-VL / 硅基流动等国内免代理 OpenAI 兼容接口及 Google Gemini 原生接口；支持 0.4x~2.0x 份量滑块微调并一键沉淀为离线模板）
  3. **内置中式常见食物与外卖离线词库**（预置主食、优质蛋白、食堂炒菜、隆江猪脚饭/麻辣烫等高频外卖与便利店食物，支持碗/拳头/掌心/克重切换）
  4. **纯数字快记 + 国内包装食品千焦 (`kJ → kcal`) 自动换算器**
- **自适应真实代谢校准 (Adaptive TDEE)**：Mifflin-St Jeor 公式起步，累积 8+ 完整记录日后结合「实际摄入 + 7 日 EMA 平滑体重趋势」自动校准真实每日消耗；内置「今日饮食未记全」防算法污染开关。
- **周热量银行**：支持工作日微存热量给周末聚餐，单日偶发超支温和分摊至本周剩余天数，并设安全保底下限。
- **原生系统触点**：`Jetpack Glance` 4x2 桌面小组件（实时看剩余热量/蛋白质，一键记餐、AI识餐、`+250ml` 静默打卡喝水）+ `WorkManager` 早晚防漏记温和本地提醒。

## 编译与安装到安卓手机

已生成的安装包路径：
`app/build/outputs/apk/debug/app-debug.apk`

### 方式一：USB / 无线调试直接安装
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 方式二：命令行重新运行测试与打包
```bash
./gradlew testDebugUnitTest assembleDebug
```
